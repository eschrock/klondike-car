## Orchestrator correction applied: Domino sizes

`DOMINOS` now carries `wMm`. Selection rule in `chooseDomino`: (a) tenon thickness ≤ 0.42 × stock, (b) mortise depth L/2 leaves ≥ `dominoMinWallIn` in the host (and in the tenon piece when `stockAlongIn` is given), (c) face width fits the joint face minus 2 × edge margin. `frameJoint()` (seat.ts) still works unchanged. Joints that changed size at the defaults: seat-back stile to rail 4×20 → **8×50**; storage lid rim corner 4×20 → **5×30**; grab-handle post to pad 4×20 → **5×30**; foot-stop cleat tenons (new) 5×30; joist to rail 5×30 (unchanged); chine to rail (new) 4×20. fittings.test.ts was updated to the new convention (face width, not length).
