Still unpriced online: 1/8" x 1-1/4" stainless strip (estimate), #10-32 hardwood inserts, 3/8" detent pins, clevis pins, a 1/4" UHMW offcut, ribbed rubber tread, an oil-embedded bronze sleeve.
